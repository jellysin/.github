# Community conduct

Discuss the code and the evidence. Disagreement is welcome; harassment, threats,
discrimination, doxxing and sustained personal attacks are not. Respect privacy and
other people's time. Keep reports actionable and review comments specific.

Maintainers may edit or remove disruptive content and restrict participation when
needed.

## Reporting conduct

Report conduct through GitHub's built-in report flow. On an issue, a pull request or a
comment, open the `...` menu and choose **Report content**. On a profile, choose
**Block or Report**. The report goes to GitHub Support. GitHub documents each step in
[Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

There is no private address for conduct reports. Security reports follow
[SECURITY.md](SECURITY.md) instead.
